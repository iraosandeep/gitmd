# GitMD

A distraction-free Markdown reader for GitHub repositories.

Paste a GitHub repository URL and GitMD extracts its Markdown files, preserves the folder structure, and presents them in a clean, book-like reading experience.

### Features

* Focused Markdown reading experience
* Light, dark, and e-ink themes
* Search Markdown files
* GitHub folder structure preserved
* Syntax-highlighted code
